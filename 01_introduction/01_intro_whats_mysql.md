# 01 - Intro & What's MySQL?

الفيديو: [مشاهدة الدرس على يوتيوب](https://www.youtube.com/watch?v=DftlOK7fCtc)

MySQL is one of the world's most popular open-source Relational Database Management Systems (RDBMS).
It is used to store, organize, and manage data using SQL (Structured Query Language).

## Key Characteristics

- **Relational Model:** Data is stored in tables, consisting of rows (records) and columns (fields).
- **Open Source:** Free to use under the GNU General Public License, with a paid Enterprise Edition for advanced features.
- **High Performance:** Known for speed and reliability. It powers big platforms like Facebook, Netflix, Uber, and Airbnb.
- **Cross-Platform:** Runs on Windows, Linux, and macOS.
- **Client-Server Architecture:** The MySQL server stores and processes the data, while client programs (like MySQL Workbench or the terminal) connect to it to run queries.

## بالعربي باختصار

MySQL نظام لإدارة قواعد البيانات العلائقية، يعني البيانات تحفظ في جداول من صفوف وأعمدة.

نتعامل معه بلغة SQL، وهو مجاني ومفتوح المصدر، ويعمل على كل أنظمة التشغيل.

يعمل بطريقة الخادم والعميل:
- الخادم يحفظ البيانات وينفذ الأوامر.
- العميل هو البرنامج الذي نكتب فيه الأوامر، مثل الطرفية أو Workbench.
