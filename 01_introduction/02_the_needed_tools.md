# 02 - The Needed Tools

الفيديو: [مشاهدة الدرس على يوتيوب](https://www.youtube.com/watch?v=z4j4S6GsxaU)

الأدوات التي استخدمتها في الدورة على نظام لينكس (Ubuntu).

## 1. MySQL Server

- **الأداة:** خادم MySQL، يثبت على النظام نفسه.
- **الوظيفة:** هو قلب قاعدة البيانات، يحفظ البيانات وينفذ الاستعلامات.
- **التثبيت:**

```bash
sudo apt install mysql-server
```

- **التأكد أن الخادم يعمل:**

```bash
sudo systemctl status mysql
```

## 2. الطرفية (Terminal)

- **الوظيفة:** منها ندخل إلى MySQL ونكتب الأوامر مباشرة.
- **اختصار فتحها في Ubuntu:** `Ctrl + Alt + T`
- **الدخول إلى MySQL بالمستخدم root:**

```bash
sudo mysql -u root -p
```

- **عرض قواعد البيانات بعد الدخول:**

```sql
SHOW DATABASES;
```

## 3. MySQL Workbench أو DBeaver

- **الأداة:** برنامج بواجهة رسومية.
- **الوظيفة:** تصميم قواعد البيانات وإدارتها، وكتابة الاستعلامات ورؤية الجداول بشكل مرئي.
- أي ملف `.sql` في هذه الدورة تقدر تفتحه فيه وتشغله.
